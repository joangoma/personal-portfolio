# Personal Portfolio

## Overview

This project is a personal portfolio website developed using React and TypeScript. It serves as both a showcase of my skills and projects, and as a learning experience in front-end development.

![Portfolio Screenshot](/public/readme_image.png)

## Live Demo

[View the live portfolio](https://joangoma.github.io/personal-portfolio/)

## Features

- Responsive design for optimal viewing on various devices
- Interactive UI components
- Project showcase with detailed descriptions
- Skills and technologies section
- About me page
- Contact section

## Technologies Used

- React
- TypeScript
- HTML5
- CSS3 (with Tailwind CSS)

## Project Goals

As my first foray into front-end development, this project had two primary objectives:

1. **Learning Experience**: To gain hands-on experience with modern front-end technologies, particularly React and TypeScript.
2. **Portfolio Creation**: To create a functional and visually appealing portfolio that effectively showcases my skills and projects.

## Challenges and Learnings

Throughout this project, I encountered and overcame several challenges:

- Understanding and implementing React component architecture
- Learning TypeScript and its integration with React
- Designing responsive layouts
- Managing state in a React application
- Implementing smooth animations and transitions

These challenges provided valuable learning opportunities and significantly improved my understanding of front-end development.
